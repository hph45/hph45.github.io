How to write a proof.

The target bar has premises to the left of ⊢ and the required conclusion to the right. Enter one proof line at a time. Carnap checks each line after a short pause; a + means the line is justified. 

P -> Q:PR
P:PR
Q:->E 1,2

Writing and structure

formula:RULE lines

Put the justification after a colon. Cite lines with numbers and subproofs with ranges such as 2-4.

two leading spaces

Indent to begin a subproof. Its first line must be an assumption. Return to the earlier indentation to close it.

--

Place two dashes between adjacent subproofs at the same level, especially for ∨E.

All allowed rules

Use the ASCII versions shown in the editor.

Setup

PR
Mark a target premise.
AS
Open an indented subproof with an assumption.
R n
Repeat the formula on line n.

Conjunction ∧

/\I m,n
Combine two lines into a conjunction.
/\E n
Take either conjunct from line n.

Disjunction ∨

\/I n
Add either disjunct to line n.
\/E n,a-b,c-d
Use a disjunction and two case subproofs ending alike.

Conditional →

->E m,n
From φ → ψ and φ, infer ψ.
->I a-b
Close a subproof from φ to ψ and infer φ → ψ.

Biconditional ↔

<->E m,n
Use either direction of a biconditional.
<->I a-b,c-d
Use subproofs proving both directions.

Negation ¬

~E m,n
From φ and ¬φ, infer contradiction.
~I a-b
If assuming φ reaches contradiction, infer ¬φ.

Classical tools

X n
From contradiction on line n, infer anything.
IP a-b
If assuming ¬φ reaches contradiction, infer φ.

This practice set uses Carnap’s basic 2019 system. Shortcuts such as DS, MT, DNE, DeM, and LEM are not accepted as single-step rules; derive their results using the allowed moves above.

Subproof example

P:PR
  Q:AS
  P:R 1
Q -> P:->I 2-3

The two spaces before lines 2 and 3 place them inside the subproof. The final line is unindented, so the assumption has been discharged.
